<h2>最終レポート内容</h2>
<li>ある半導体製造工程では，製品の品質検査のコストを下げるためにVM（仮想計測：Virtual Measeurment）という技術が導入されている．VMは端的に言えば各工程における計測値から製品品質の予測を行い，その予測品質がある一定ラインを下回ったら実際の検査に回すというものである．ここで重要となってくるのは，VMの予測精度が低いと，不良品が良品として検査が実施されなかったり，その逆があり得るということである．故にVMの予測精度を如何に向上させるかが重要な課題となる．
